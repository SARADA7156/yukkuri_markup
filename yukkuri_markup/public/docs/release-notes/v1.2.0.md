## ｖ1.2.0リリースハイライト
v1.2.0アップデートではプレビュー画面周りの機能が強化され、フレーズごとの尺や台本全体の尺の予想が表示される機能が追加されました。
また、UIの調整やパフォーマンスの改善も行われました。

## 追加機能
- **読上げ時間予想:** 入力した文字数からYMM4で動画を再生する際に、どれぐらいの読み上げ時間を要するのかを予想し表示する機能を追加しました
- **総読上げ時間予想:** 全てのフレーズの読み上げ時間を計算し、台本全体でどれぐらいの尺を要するのかを予想しステータスバーに表示する機能を追加しました
- **ウィンドウサイズ・位置の記憶:** アプリが起動する際、前回起動していたウィンドウサイズと位置に復元されるようになりました。(マルチモニターや解像度の関係から、安定しない場合がございます)

読上げ時間予想の詳しい解説は、画面左上のヘルプページをご覧ください。

## 変更・修正点
- マークアップ構文の構文解析のパフォーマンスを改善しました
- キャラクター・感情フラグの編集機能を追加しました
- エディターの内部データの構造を改善し、プレビュー画面表示のパフォーマンスを改善しました
