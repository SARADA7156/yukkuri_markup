## v1.0.0リリース
ゆっくりマークアップ v1.0.0 がリリースされました。ゆっくり音声の台本制作を効率化し、動画のクオリティをさらに高めましょう！

## 主な機能
- **専用マークアップの構文:** 専用マークアップにより台本制作の時間を短縮
- **台本プレビュー画面:** 実際の台本を表示
- **マークアップフラグ挿入ショートカット:** キャラクター・感情フラグのパレット押し、マークアップの入力を簡略化
- **カスタムキャラ・感情フラグの追加:** 自分オリジナルの要素を追加し、カスタマイズすることが可能。
- **台本エディターステータスバー:** エディター内の文字数と行数をカウントする機能
