# 【YMU】ゆっくりマークアップとは？
本アプリケーションはゆっくり実況の台本を作成する手間や負荷を軽減するために開発されたアプリケーションです。
左側のエディターにカスタムマークアップを記述し、右側に台本のプレビューが出力されます。
本アプリケーションは *GPL v3* ライセンスを適応したOSSであり、基本的にすべてのコードが公開されております。

### 外部との通信について
本アプリケーションは利用者の台本データが、他人に公開・流出される可能性を保護されるため、**基本的に通信は行いません。**
ただ、今後の追加機能としてアップデートの自動検知に限り通信を行う方針に変更します。

### このアプリは個人開発！開発者は誰？
プログラミングが大好きな学生です。
※そのため突然開発やアップデートが止まる可能性があります。

# 今後のアップデート
1.0リリース後も順次アップデートを進めていくつもりです。

### 自動アップデート機能について
利用者の更新忘れを防ぐため、自動的にアプリケーションがアップデートされる機能を搭載する予定です。(※現在はまだ追加されていません。)
自動アップデート機能の追加前に、新しいバージョンが公開されている場合に通知を出現させる機能を追加する予定です。

概要でも記述されておりますが、新しいバージョンが公開されているかどうかを確認する場合に限り、外部との通信を行います。またこれは設定画面でオフにすることが可能です。

### 今後のアップデートで追加する予定の機能
#### 各行ごとの台本コピー機能
YMM4に台本を入力する手間を軽減するために、行ごとにクリップボードに台本のセリフがコピーされます。

#### エディター内補完
本アプリケーションはエディター内でカスタムマークアップを使用しております。そのため、マークアップ入力の手間を軽減するためにマークアップフラグの候補を表示し、TabキーやEnterキーを入力すると自動的に挿入される機能です。
この機能は比較的早めの段階で追加する予定です。

#### ファイル読込み・出力機能
独自形式のファイルを読込みエディター内で再編集したり、エディター内で入力した台本テキストを、専用形式のファイルに出力する機能です。専用形式のファイルの内部構造はJSON形式であり、ファイルの拡張子のみが独自の物に変更される予定です。
また、YMM4にそのまま読み込めるようにCSVやプレーンテキスト形式での出力も対応させる予定です。

#### フレーズ毎・台本全体の読上げ時間予測
ワンフレーズ（1行）にかかる読上げ時間や、台本全体でかかる読上げ時間を予測し、動画全体の尺を把握する補助機能です。YMM4で設定してあるゆっくり実況の読上げ速度や1行ごとに読上げ速度が設定できる機能を追加させる予定です。

#### UIの刷新
後述の『ローカルAIによる台本制作補助エージェント』に対応させるために画面の構成や挙動をより使いやすく変更する予定です。

#### ローカルAIによる台本制作補助エージェント(v2.0予定)
ユーザーが入力したデータを内部で動作させているAIが学習し、次に来る文章や単語、キャラクターの固有フレーズの候補を出します。AIによるアシスタントをオフにする機能を付ける予定です。
また、ユーザーが入力したデータは内部で保持されるだけであり、外部のサーバーにインターネットを介して送信される事はありません。
※AIによるアシスタント機能は学生個人が開発するにはあまりにも作業量が多いため、実装されない可能性があります。
